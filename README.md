# Tienda 3D

Página de una sola hoja para mostrar peluches y productos 3D y recibir pedidos por WhatsApp.

## Cómo cambiar tus datos y productos

Todo se edita en **`productos.js`**:

- `TIENDA`: nombre, eslogan, número de WhatsApp (con 57 adelante, sin + ni espacios), Instagram y TikTok.
- `PRODUCTOS`: la lista del catálogo. Copia un bloque `{ ... }` para agregar uno nuevo.

Para poner fotos reales, súbelas a la carpeta `fotos/` y escribe en el producto `foto: "fotos/nombre-de-la-foto.jpg"`.

Puedes editar el archivo directo en GitHub (botón del lápiz ✏️) y guardar con "Commit changes".

## Dónde está publicada

La página está en Vercel: **https://tienda-3d-omega.vercel.app**

Cada vez que guardas un cambio en la rama `main` de este repositorio, Vercel la vuelve a publicar sola en uno o dos minutos.

## Sobre derechos de autor

Publica fotos de tus diseños originales. Si un cliente pide un personaje con marca registrada, que lo cuente por WhatsApp en privado y no lo subas a la página ni a redes.
